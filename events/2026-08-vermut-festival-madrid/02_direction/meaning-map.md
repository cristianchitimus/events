# Meaning Map — CRUDO

> Format: **Element → Functional Job → Meta-message → Emotion**
> Read by Nodes 3, 4, 5, 8 to keep every output anchored to a coherent identity.

---

### 1. Rojo Crudo (`#E5261C`) as primary
- **Functional job:** main brand recognition signal across all surfaces; works at thumbnail size
- **Meta-message:** this isn't safe heritage; this isn't curated; this is a *signal*
- **Emotion:** urgency, defiance, immediacy

### 2. Archivo Black headlines, set tight, often UPPERCASE
- **Functional job:** primary headline communication on banners, posters, screens, OOH
- **Meta-message:** we're not curating a museum; we're throwing a party and we want you in it
- **Emotion:** impact, conviction, no-apology

### 3. Asymmetric grids; content bleeds to canvas edges
- **Functional job:** information hierarchy that refuses centered-classical "respectful poster" rules
- **Meta-message:** rules optional; the brand is not asking permission
- **Emotion:** looseness, irreverence, claim-making

### 4. Blown-flash venue photography
- **Functional job:** primary visual storytelling — shows what the venue actually feels like, not what the tourism board wants it to feel like
- **Meta-message:** the market is real, not a backdrop; the heritage is alive, not preserved
- **Emotion:** honesty, presence, *being there*

### 5. Oversize numerals (Space Mono / Archivo Black) — dates, stage IDs, prices, set times
- **Functional job:** wayfinding + graphic anchor; turns logistical info into visual identity
- **Meta-message:** the festival is structured; the brand is wild; we're trustworthy *and* loud
- **Emotion:** orientation, confidence, anchoring

### 6. Tight margins; bleed-to-edge layout
- **Functional job:** spacing that disrespects the precious-poster / generous-margin tradition
- **Meta-message:** the brand takes up space without permission; we're not making it pretty for you
- **Emotion:** boldness, claim-making, refusal

### 7. Visible print artifacts (registration crosses, halftone, photocopy noise, CMYK misregistration)
- **Functional job:** texture across all surfaces — print + digital
- **Meta-message:** made by hand, not by an agency; the seams are part of the design
- **Emotion:** authenticity, scrappy energy, anti-corporate

### 8. Bold red ✕ (cross-out / scratch-out) as signature graphic element
- **Functional job:** marks edits, redacts copy, calls out cancelled or moved items, anchors callouts and "FROM / TO" patterns
- **Meta-message:** we leave the seams visible; we cross things out instead of hiding them
- **Emotion:** editorial honesty, irreverence, energy

---

## How to use this map at downstream nodes

- **Node 3 (logo):** the wordmark must perform Element 2 + Element 6 (chunky, bleed-tolerant). It must NOT carry illustrative motifs; those belong on the surface, not in the mark.
- **Node 4 (hero):** must combine Element 1, 4, and 5 — flash photography of venue + Rojo Crudo overlay + oversize date numerals.
- **Node 5 (banners):** copy must perform Element 8 spirit — direct, unedited, scratched-out where appropriate.
- **Node 8 (print):** wristbands and signage must show Element 7 (visible printing artifacts, registration marks) explicitly.
